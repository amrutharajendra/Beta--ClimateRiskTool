**Climate Risk & TARP Tool**

This tool helps generate a project-specific Trigger Action Response Plan (TARP). Enter your project's state, season, construction activity and site conditions, and it shows you the climate hazards that apply, the T1–T3 trigger thresholds, and the mitigation actions for each one.

Anyone on the project team who needs to look up or generate a TARP can use this html page.

Step 1: Get the data in your desktop
- Download the 3 sheets in UTF-8 CSV formats as Database.csv, TARP_ERP.csv, Project_Questionaire.csv)

Step 2: Get the tool onto your computer
- Go to the repository page.
- Click **Code** and Click **Download ZIP**
- Find the downloaded ZIP file (usually in your Downloads folder) and extract it
- You'll end up with a regular folder containing the tool's file.
OR
- Open this link - https://amrutharajendra.github.io/Beta--ClimateRiskTool/climate-risk-finder.html

Step 3: Open the tool
- Open the file called climate-risk-finder.html
- It will open automatically in your default web browser (Chrome, Edge etc.).

Step 4: Use the tool
- Upload the 3 csv sheets
- Fill in the project details requested on screen: state/territory, season, construction activity, and site conditions
- The tool will display:
- The climate hazards that apply to your project
- The T1, T2 and T3 trigger thresholds for each hazard
- The mitigation action required at each level
